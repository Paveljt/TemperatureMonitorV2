# Temperature Monitor V2

Temperature Monitor V2 is an embedded systems project that monitors temperature using an Arduino-compatible microcontroller and PlatformIO.

The project demonstrates sensor interfacing, embedded C/C++ programming, serial monitoring, debugging, and hardware-software integration.

## 🌐 Live Project Website

View the project showcase here:

https://temperature-monitor-project.vercel.app/

## 🛠 Technologies Used

- C/C++
- PlatformIO
- Arduino-compatible hardware
- Temperature sensor
- Git
- GitHub

## 📁 Project Structure

- `src/` — main source code
- `include/` — header files
- `lib/` — project libraries
- `test/` — test files
- `platformio.ini` — PlatformIO configuration
- `diagram.json` — circuit/project diagram

## 🎯 Project Purpose

The purpose of this project is to monitor temperature readings using an embedded system and demonstrate how hardware sensors can communicate with software running on a microcontroller.
